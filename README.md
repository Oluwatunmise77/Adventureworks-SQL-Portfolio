# AdventureWorks SQL Portfolio Project

## Project Overview

This project involves analyzing the AdventureWorks database using SQL to answer 15 real-world business questions.

The objective is to demonstrate practical SQL skills and generate business insights from sales, customers, products, employees, territories, and suppliers.

## Tools Used

* MySQL Workbench
* SQL
* GitHub

## Project Objectives

The project aims to:

* Analyze product and sales performance.
* Identify high-value customers and top-performing store accounts.
* Evaluate sales representative and territory performance.
* Investigate product inventory levels and stock alerts.
* Analyze employee compensation, department rosters, and supplier/vendor pricing.

## SQL Skills Demonstrated

* SELECT statements
* INNER JOINs
* GROUP BY and HAVING clauses
* ORDER BY, LIMIT, and sorting
* Aggregate functions (SUM, AVG, COUNT)
* Subqueries and Correlated subqueries
* NOT IN subqueries
* Data filtering and condition matching

## Business Questions

The project addresses 15 business questions across five key operational areas:

1. **Sales & Customer Analytics** (High-value orders, company averages, top store accounts, and unordered catalog products)
2. **Product & Inventory Management** (Subcategory pricing analysis, bicycle catalog filtering, and low-stock alerts)
3. **Human Resources & Employee Metrics** (Above-average employee earnings and manufacturing department staff rosters)
4. **Purchasing & Vendor Management** (High-cost component vendors, purchase order comparisons, and multi-credit card profiles)
5. **Advanced Sales & Operations Analysis** (Top-performing sales reps per territory, shipping cost outliers, and high-discount bulk special offers)

## Conclusion

This project demonstrates the application of SQL to business analysis and decision-making. It highlights how relational databases can be queried using joins, subqueries, and aggregations to identify trends, evaluate operational performance, and support informed business strategies.
